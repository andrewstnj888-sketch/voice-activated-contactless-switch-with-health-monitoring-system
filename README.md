# Voice Activated Contactless Switch with Health Monitoring System

An ESP32-based contactless appliance control system using
voice commands and real-time electrical health monitoring.

## Features

- Voice controlled LED
- Voice controlled motor
- Temperature monitoring
- Voltage monitoring
- Current monitoring
- Power monitoring
- Real-time display
- ESP32 control
- Python voice recognition

## Hardware

- ESP32
- INA219
- DHT11
- Relay module
- LED
- Motor
- OLED/TFT display

## Software

- Arduino IDE
- Python 3.12
- VS Code
- GitHub
